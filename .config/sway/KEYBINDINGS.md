# Sway keybindings

`Super` is the main modifier.

| Keys | Action |
|---|---|
| `Super+N` or `Super+Enter` | Terminal |
| `Super+P` | Fast application launcher |
| `Super+D` | Unified dashboard: controls and notifications |
| `Super+W` | Fuzzy-search every open window |
| `Super+Tab` | Jump to the last-used window |
| `Super+Shift+W` | Search workspaces and windows |
| `Super+Ctrl+W` | Bring a chosen window to this workspace |
| `Super+grave` | Toggle drop-down quick terminal |
| `Super+V` | Search clipboard history |
| `Super+Q` | Close focused window |
| `Super+Space` | Toggle floating |
| `Super+M` or `Super+F` | Toggle fullscreen |
| `Super+H/J/K/L` | Focus left/down/up/right |
| `Super+Arrow` | Focus by direction |
| `Super+Shift+H/J/K/L` or `Super+Shift+Arrow` | Move window left/down/up/right |
| `Super+R` | Resize mode: H/Left narrows, L/Right widens, J/Down grows vertically, K/Up shrinks |
| `Super+1` through `Super+0` | Workspace 1 through 10 |
| `Super+Shift+1` through `Super+Shift+0` | Move window to workspace |
| `Super+I` / `Super+O` | Previous / next numeric workspace on this monitor; creates it when needed |
| `Super+Ctrl+I` / `Super+Ctrl+O` | Move the focused window to the previous / next local workspace and follow it |
| `Super+Shift+Tab` | Last workspace |
| `Super+,` / `Super+.` | Focus left / right monitor |
| `Super+Shift+,` / `Super+Shift+.` | Move workspace to left / right monitor |
| `Super+Shift+S` | Region screenshot and annotation |
| `Super+Ctrl+S` | Window screenshot and annotation |
| `Print` | Output screenshot and annotation |
| `Super+Ctrl+L` | Lock |
| `Super+Esc` | Session/power menu |
| `Super+B` | Toggle top bar |
| `Super+Shift+C` | Reload Sway config |
| `Super+Shift+D` | Graphical display settings; saves automatically to kanshi |
| `Super+Shift+Q` | Confirm logout |
| `Super+Shift+/` | Searchable shortcut help |
